Gemma 4 Neo — hybrid architecture
Transformer + SSM + SNN: o melhor dos três mundos, mapeado camada a camada

O que muda em cada camada

35 camadas locais SWA (q=2048, k/v=512) → Mamba-2 SSM O(1)/step, sem KV cache
7 camadas globais Full attn (q=4096, k/v=1024) → Gated Attention + SnapKV + sigmoid gate
42 MLPs GELUTanh, denso → ReLU² + SpikeSparse 50–70% zeros
todos os pesos BF16/FP16 → W4A8 quantization + KV-INT8 (7 layers)
per_layer_input_gate bottleneck 2560→256 → dynamic sparsity predictor

Analogia cerebral

  • Mamba-2: memória de trabalho recorrente — como o hipocampo codifica sequências com estado comprimido
  • Gated Attention: atenção focal — como o córtex pré-frontal acessa o contexto global seletivamente
  • ReLU² + SpikeSparse: disparo spiking — neurônios só ativam quando estimulo supera threshold
  • Per-layer gate: neuromodulação — dopamina/serotonina decidindo quais circuitos ativar
  • SnapKV: memória episódica seletiva — hipocampo descarta memórias irrelevantes

Inovação 1 — SSM backbone

Mamba-2 como espinha recorrente

Substitui os 35 blocos SWA locais. Estado comprimido O(d_state) por layer — sem KV cache. Ao contrário do RNN clássico, o Mamba-2 tem paralelismo de treinamento via scan seletivo. Captura dependências longas com estado fixo de ~64–256 dimensões vs KV de 512 por layer no original.

Ganho: 83% do KV cache eliminado. Decode O(1) por step em vez de O(n).

Inovação 2 — Gated Attention

Atenção focal com gate sigmoid

Os 7 layers globais viram Gated Attention (NeurIPS 2025 Best Paper). Um gate σ(X·Wθ) por cabeça modula a saída de atenção — se o gate for ~0, a cabeça contribui zero sem precisar computar o softmax completo. Elimina attention sinks e melhora extrapolação de contexto longo. Combinado com SnapKV: top-k tokens relevantes via KV-summary.

Ganho: KV cache só nos 7 layers globais, com 80% dos tokens descartáveis via SnapKV.

Inovação 3 — ReLU² + SpikeSparse

MLPs event-driven

GELUTanh → ReLU²(x) = max(0,x)². Produz zeros exatos com esparsidade ~50–70%. O per_layer_input_gate do Gemma 4 (2560→256) vira preditor: sua magnitude prevê quais das 10.240 dimensões da MLP precisam ser computadas. SpikingBrain-style: threshold por neurônio calibrado em dataset pequeno, sem retreino completo.

Ganho: ~50–70% de FLOPs no MLP eliminados. CPU-friendly: skip de linhas inteiras da weight matrix.

Inovação 4 — W4A8 + KV-INT8

Quantização em cascata

Pesos → INT4 (AWQ/GPTQ). Ativações → INT8 (SmoothQuant nos residuals). KV cache dos 7 layers globais → INT8. Combinado com esparsidade ReLU²: os neurônios que disparam são em INT8, os que não disparam são zero — não precisam sequer ser dequantizados. Resultado: pipeline compute-bound nos layers Mamba (scan), memory-bound mínimo nos layers globais.

Ganho: 4× memória de pesos + 8× KV cache + 2× compute via INT8 kernels.

Inovação 5 — Per-layer gate reaproveitado

Gate existente como neuromodulador

Gemma 4 já tem per_layer_input_gate: Linear(2560→256) + RMSNorm + Linear(256→2560). A norma L2 do vetor 256-dim prevê importância de cada neurônio na MLP daquele layer. Threshold calibrável por layer sem retreino. Neurônios com score abaixo do threshold são pulados. Análogo exato à neuromodulação dopaminérgica.

Gain: esparsidade dinâmica e input-dependent — cada token ativa subconjunto diferente de neurônios.

Inovação 6 — Speculative decoding

Codificação preditiva: E2B → E4B

E2B como modelo draft (2B params ativos), E4B como verifier. O draft propõe k tokens em paralelo — o verifier aceita ou rejeita em um único forward pass. Taxa de aceitação ~70–80% para linguagem natural. Combina com todo o stack acima: o draft já usa Mamba-2 + ReLU², o verifier valida apenas o que importa.

Ganho: 2–4× speedup de tokens/segundo sem nenhuma perda de accuracy.

Pipeline de conversão — ordem e custo

Cada passo é incremental e reversível. Pode-se parar em qualquer ponto e ter ganhos parciais.

1
Quantização W4A8 + KV-INT8
Zero retreino. AWQ calibration (~1h). Redução imediata de memória 4×. Funciona como base para todos os passos seguintes.
Custo: 1h GPU Ganho: 4× memória
2
SnapKV + PagedAttention (serving layer)
vLLM config. Sem mudança de pesos. KV eviction nos 7 layers globais. Continuous batching. Ganho imediato em throughput de serving.
Custo: config Ganho: 2× throughput
3
GELUTanh → ReLU² + threshold gate
Substituição de ativação + calibração do per_layer_input_gate como preditor de sparsidade. Fine-tuning leve: ~30B tokens. Esparsidade de ativação 50–70%.
Custo: ~1 semana GPU Ganho: ~2× FLOPs MLP
4
Gated Attention nos 7 layers globais
Adiciona Wθ sigmoid gate após SDPA em cada cabeça. Inicialização com ones — gate começa transparente. Fine-tuning ~50B tokens para estabilizar. Elimina attention sinks, melhora contexto longo.
Custo: ~2 semanas GPU Ganho: qualidade + estabilidade
5
SWA → Mamba-2 nos 35 layers locais
Conversão por distilação: Mamba-2 imita saída dos layers SWA via MSE loss. Passo mais intenso: ~150B tokens de continual pre-training. SpikingBrain mostrou que ~2% do compute original é suficiente para recuperar acc.
Custo: ~1–3 meses GPU cluster Ganho: 8–10× decode speedup
6
SFT final + speculative decoding E2B→E4B
Fine-tuning supervisionado para realinhamento de instrução. Configurar E2B-Neo como draft model para E4B-Neo ou 27B-Neo. 2–4× speedup adicional sem acc loss.
Custo: ~1 semana Ganho: 2–4× tokens/s
