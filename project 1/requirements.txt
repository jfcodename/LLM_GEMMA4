## Quickstart — conversão em 3 passos

### Passo 1: Conversão básica (zero retreino, impacto imediato)

```bash
# Aplica quantização NF4 + ReLU² + Gated Attention
python convert.py \
  --model google/gemma-4-e2b-it \
  --steps quant relu2 gated_attn \
  --output ./gemma4_neo_e2b \
  --sparsity 0.65 \
  --calibrate

# Resultado: ~4× menos memória, ~2× mais rápido, <1% acc loss
```

### Passo 2: Inferência com o modelo convertido

```bash
# Geração simples com streaming
python inference.py \
  --model ./gemma4_neo_e2b \
  --prompt "Explique como funciona a atenção em transformers" \
  --stream

# Benchmark completo
python inference.py \
  --model ./gemma4_neo_e2b \
  --benchmark \
  --monitor-sparsity
```

### Passo 3: Destilação Mamba-2 (máximo ganho, requer treino)

```bash
# 1. Destila os 35 layers locais (~1 semana, 1×A100)
python mamba2_distill.py \
  --teacher google/gemma-4-e2b-it \
  --output ./mamba2_weights_e2b \
  --steps 50000 \
  --batch-size 8 \
  --max-length 2048

# 2. Valida qualidade da destilação
python mamba2_distill.py \
  --teacher google/gemma-4-e2b-it \
  --output ./mamba2_weights_e2b \
  --validate-only

# 3. Converte com Mamba-2
python convert.py \
  --model google/gemma-4-e2b-it \
  --steps quant relu2 gated_attn mamba2 \
  --output ./gemma4_neo_e2b_full \
  --mamba-weights ./mamba2_weights_e2b

# Resultado: ~10× menos memória, ~8× mais rápido, ~2-3% acc loss
```

## Uso programático

```python
from config import Gemma4NeoConfig
from convert import Gemma4NeoConverter

# Config customizada
config = Gemma4NeoConfig(
    base_model_id="google/gemma-4-e2b-it",
    output_dir="./meu_neo",
)
config.relu2.sparsity_target = 0.60       # menos agressivo
config.gated_attention.snap_kv_window = 2048  # janela maior
config.quantization.use_bnb = True

# Converte
converter = (
    Gemma4NeoConverter(config)
    .load_base_model()
    .apply_relu2_mlp()
    .apply_gated_attention()
    .apply_quantization()
)
converter.report()
converter.save()
```

```python
from inference import Gemma4NeoInference

# Carrega e usa
neo = Gemma4NeoInference("./meu_neo")
result = neo.generate_with_stats(
    "Escreva um poema sobre inteligência artificial",
    max_new_tokens=200,
    temperature=0.8,
)
print(result["text"])
print(f"Velocidade: {result['performance']['tokens_per_sec']:.1f} tok/s")
print(f"Sparsidade MLP: {result['sparsity']['mean']:.1%}")
```

## Estrutura dos arquivos

```
gemma4_neo/
├── config.py           — Configuração de todas as modificações
├── modules.py          — Implementações: ReLU², GatedAttn, SnapKV, Mamba-2
├── convert.py          — Script principal de conversão (carrega pesos + aplica mods)
├── mamba2_distill.py   — Destilação de conhecimento SWA → Mamba-2
├── inference.py        — Inferência otimizada + benchmark + speculative decoding
└── requirements.txt    — Este arquivo
```

---

## Mapeamento de modificações → arquitetura Gemma 4

| Componente original | Componente Neo | Arquivo | Layers |
|---|---|---|---|
| `GELUTanh` em MLP | `ReLU²` + mascaramento | `modules.py:ReLU2GatedMLP` | Todos (0–41) |
| `per_layer_input_gate` | SparsityPredictor | `modules.py:SparsityPredictor` | Todos (0–41) |
| Full Attention global | Gated Attention + SnapKV | `modules.py:GatedAttentionLayer` | 5,11,17,23,29,35,41 |
| SWA local (q=2048) | Mamba-2 SSM | `modules.py:Mamba2Block` | 0–4,6–10,…,36–41 |
| BF16 pesos | NF4/INT4 | `convert.py:apply_quantization` | Todos |
