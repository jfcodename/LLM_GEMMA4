Estratégia de transferência de pesos (dense → sparse)

2:4 structured (NVIDIA ASP)
✓ magnitude pruning direto nos pesos treinados
✓ sem retreino — aplicar post-hoc
✓ 2x speedup garantido em Ampere+
✗ degradação ~1–3% sem fine-tuning
✗ 2:4 colapsa reasoning em alguns modelos (Qwen3: 54→15%)
Unstructured L1 (Sakana+NVIDIA)
✓ preserva acurácia com >90% esparsidade
✓ L1 reg. + fine-tuning nos pesos existentes
✓ mais flexível — sem restrição de padrão
✗ precisa de kernels CUDA customizados
✗ speedup depende de implementação
6:8 / SlideSparse
✓ 75% de não-zeros, quase sem perda
✓ decompõe em janelas 2:4 compatíveis
✓ preenche gap entre dense e 2:4
✗ requer SlideSparse runtime
✗ ainda experimental
Gemma4ClippableLinear
✓ vision + audio já têm wrapper de clip
✓ mecanismo de mascaramento já existe
✓ pode ser estendido para sparse mask
✗ text layers usam Linear puro
✗ precisa refatorar text decoder
